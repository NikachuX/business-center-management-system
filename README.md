## Описание проекта
Проект представляет собой программный комплекс информационной системы для автоматизации процессов управления объектами коммерческой недвижимости современного бизнес-центра. 
Основной автоматизируемый бизнес-процесс — **«Обработка заявки арендатора и заключение договора аренды коммерческого помещения»**. 

## Версия Python и зависимости

Python 3.10 или новее. Проверено на Python 3.14.3. Используется только стандартная библиотека, установка пакетов не требуется. Файл requirements.txt не нужен.

## Как запустить

Распакуйте архив и откройте терминал в корне проекта — в папке, где находятся `README.md` и `src`. Все команды ниже выполняются из этой папки.

### Python

```bash
python src/python/main.py
```

### Java

Нужен **JDK 21 или новее** с командами `javac` и `java`. Сторонние библиотеки не требуются.

**Windows PowerShell**

```powershell
New-Item -ItemType Directory -Force out | Out-Null
$files = Get-ChildItem -Path .\src\java -File -Filter '*.java' | ForEach-Object { $_.FullName }
javac -encoding UTF-8 -d out $files
java -cp out Main
```
