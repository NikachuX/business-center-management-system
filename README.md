## Описание проекта
Проект представляет собой программный комплекс информационной системы для автоматизации процессов управления объектами коммерческой недвижимости современного бизнес-центра. 
Основной автоматизируемый бизнес-процесс — **«Обработка заявки арендатора и заключение договора аренды коммерческого помещения»**. 

## Версия Python и зависимости

Python 3.10 или новее. Проверено на Python 3.14.3. Используется только стандартная библиотека, установка пакетов не требуется. Файл requirements.txt не нужен.

python src/main.py
